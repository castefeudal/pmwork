# Product contract

PMWORK connects understand → decide → do → control → learn in one device-local workspace.

## Current behavior

1. First run offers create, explicit demo and validated restore. No automatic demo persistence.
2. All levels start at Today. Foundation includes expandable purpose/action/output/mistake explanations. Guidance and density are independent.
3. Desktop navigation groups management, delivery, control, collaboration and system. Narrow-screen navigation has Overview, Work, Planning, Guide and More.
4. URL state preserves project, view, layout and operational tabs; language switching preserves URL and persisted data.
5. Glossary supports 172 bilingual concepts, twelve categories, levels, aliases, fuzzy search and individual term routes.
6. Public search covers methods, templates, playbooks, knowledge, glossary and tools. Method fit is a heuristic score, not a success probability.
7. Template application uses an explicit destination and supports open/undo. New-project state contains no demo records.
8. Mobile Work uses cards; Planning presents dates and milestones with an optional full timeline.
9. Local project identity supports My work. Risk conversion creates a linked issue; a deterministic status draft creates an editable document.

Historical prompts under `archive/` are superseded as descriptions of the current implementation. The user execution specification remains the acceptance target; a feature is only verified when its associated release evidence passes.

## Transformation scope

See TRANSFORMATION_STATUS.md for the exact implemented slice and remaining acceptance gaps. New project context is persisted; Today links to records; tools can reuse compatible project data. This is a personal, device-local PM workbench.
