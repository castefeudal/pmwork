# Content model

The seed glossary contains 172 original bilingual definitions and examples. `GlossaryTerm` supports slug, English/Russian names, acronym, aliases, category/subcategory, practical-use level, definition, plain language, purpose, example, context, relationships, confusion pairs, tags, workspace/method/template/tool links, source IDs and review date.

Twelve categories are explicit. Aliases resolve to the canonical concept. Validation checks duplicate names/slugs, translations, category/level, relations, source IDs, empty aliases and placeholders. Some enrichment fields currently reuse category-level guidance or remain empty; term-specific editorial enrichment is not certified complete.

Methods retain original source records and receive individual implementation notes. Their source registry distinguishes standards, official guides and practice. Shared generic secondary fields still require editorial review before claiming every method field is individually authored.

47 templates, 39 playbooks and 26 knowledge domains are retained. Templates are selected by collection and require a destination project. The foundation learning path is a navigation sequence through existing practical knowledge guides.
